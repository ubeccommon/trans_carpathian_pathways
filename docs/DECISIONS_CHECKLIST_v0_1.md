*Michel's word, October 9, 2026: the decisions S-1 to S-24 from
the stress tests wait and will be taken later; this is the list
of questions to answer when they are. Each line is one question,
with its source (S for the stress tests, A for the agreement's
open items, OI-P for the starting prompt's) and the document its
answer changes. Where a test recommended an answer it is given
after "→" as a proposal, not a decision. Answer in any order; the
first four are the ones the tests ranked highest.*
